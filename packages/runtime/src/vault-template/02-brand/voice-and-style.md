# Voice and style

## Default voice

Direct. Specific. Human.

Short lines when the pacing earns them. The writing should feel spoken, but not careless.

## Good textures

- Concrete numbers.
- Real timestamps.
- Specific tools.
- Honest uncertainty.
- A small joke when the line earns it.
