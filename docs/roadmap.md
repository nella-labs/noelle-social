# Roadmap

Noelle focuses on social growth workflows that can be configured, reviewed and verified.

## Current work

- A clear workspace for Overview, Engage, Content, People and Settings.
- Flat platform profiles with explicit objectives, workers, budgets and sender permissions.
- A documented local installation using an operator owned database and provider credentials.
- Reusable controls and contracts with tests for their affected consumers.

## Priorities

- Improve first run setup and explain each platform's required connection and capability.
- Make incomplete worker, review and delivery states easier to inspect.
- Expand clean installation, disposable database and browser validation.
- Improve comparable outcome measurements and their use in drafting.
- Document shared hosting and contribution paths without relying on private infrastructure.

Proposed work is discussed in repository issues. This page does not promise release dates or unimplemented platform support.
