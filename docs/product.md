# Product

Noelle helps an operator grow a social presence through relevant conversations and useful content. It supports X, LinkedIn, Reddit and video workflows.

## Workspaces

| Workspace | Purpose |
| --- | --- |
| [Overview](social-growth.md) | Inspect channel state, pending work and observed results |
| [Engage](social-growth.md#review-conversations) | Review reply and message drafts with their source evidence |
| [Content](content-workspace.md) | Develop ideas, edit original posts, manage media and plan publication |
| [People](social-growth.md#review-conversations) | Save people, profiles, notes and recorded interactions |
| [Settings](self-host.md#workers-and-publication) | Configure channels, voice, provider connections, account access and workspace controls |

Platform profiles use the existing names Vega for X, Lyra for LinkedIn, Orion for Reddit and Nova for video. Each profile has its own supported workers and sender contract. A configured profile does not imply that every lane is running.

## How work moves

Discovery saves candidate conversations and source measurements. Classification records relevance. Drafting uses the objective, saved account context and writing rules. Review presents the draft and its evidence. Dispatch uses the platform's configured permission and sender gates. Metrics record observed outcomes when a supported collector has access.

Original post generation currently supports X and LinkedIn. Reddit focuses on replies. Video workflows manage source clips, ideas, drafts and recording material; publishing capability depends on the configured integration.

## Scope

Social content, replies, outreach, contacts, platform configuration and measured learning belong in the product. General company management, finance, hiring, calendars and task delegation are outside its scope.

Noelle requires your own provider credentials and social account access for connected workflows. Provider calls can incur charges. A missing measurement stays unknown, and a generated draft has no delivery receipt until the platform confirms an action.
