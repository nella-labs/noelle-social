# Social growth workflow

Start with one platform, a clear objective and a small reviewable queue.

## Set up a profile

Open Settings → Channels, choose the platform profile, and set its objective, audience, budgets and worker controls. Use the connected account and provider settings for the required access. Keep publication disabled until the account and sender settings are verified.

Workers are separate processes. On a local installation, enable them through the CLI and start the managed stack as described in [self hosting](self-host.md). Turning on a dashboard lane cannot create a worker process that is absent from the installation.

## Review conversations

Add relevant people or topics to a watchlist, or enable the supported discovery lane. Classification supplies a lead score and source context. The reply drafter writes against that saved evidence.

Open Engage to inspect the source, writing checks and proposed reply. Edit, skip or restore a draft through its existing controls. Platform filters and Review or Speedrun mode change the view. Sending remains governed by the current platform contract and configured permissions.

Friendly DMs use saved people and recent source evidence. Their own evidence verdict is separate from a reply's writing check. See [Friendly DMs](friendly-dms.md) for caps and duplicate rules.

## Create original content

Use Content to save a premise, request ideas, generate platform versions and revise the drafts. The same idea can produce separate X and LinkedIn versions. Scheduling, marking a draft ready and confirmed publication are distinct states.

Save media and recording material with the relevant idea or draft. Read [the content workspace guide](content-workspace.md) for data ownership and [MCP creation](mcp-creation.md) for request and result tools.

## Learn from results

Record the published URL when a workflow requires it. Supported collectors save outcomes and their observation times. Compare measurements taken under comparable conditions. Missing reach or engagement values are not zero, and a lead score is not a prediction of distribution.

Use those results, your edits and saved context to improve the next objective or draft. Keep only the lanes and sources that support the current goal.
